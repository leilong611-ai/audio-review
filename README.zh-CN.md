# Local Audio Workbench｜本地录音工作台

在 Mac 上把音频转成带时间戳的中文转写。你可以点击时间戳回听，修改文字并保存校对版本。工作台保留导入的原音和第一次机器转写结果。

## 第一次试用

当前候选已在 macOS 27.2.1 实测。欢迎反馈 macOS 26 的首次安装结果。

1. 准备 macOS 26 或更新版本、Python 3.9 或更新版本、带 macOS 26 或更新 SDK 的 Xcode 工具链，以及系统已安装的简体中文 Apple 语音资产。浏览器用于操作本机工作台。
2. 下载源码并解压。在终端进入解压目录，运行 `/bin/zsh ./Start.command --check`。首次检查会在项目内编译转写工具。出现“已就绪”后，运行 `/bin/zsh ./Start.command`。
3. 另开一个终端，也进入解压目录，再运行 `/bin/zsh ./samples/make-demo.command`。它会在本机按[虚构文稿](samples/演示脚本.txt)生成一条个人试用 WAV，并打印文件路径。打开工作台地址，默认是 `http://127.0.0.1:8879`。点击「导入录音」，选择刚生成的文件，也可以使用有权处理的自有音频。
4. 点击「本机转写」。点击任意一段时间戳回听。点击「开始校对」，改一段文字后点「保存校对」。刷新页面确认版本已保存。可在「查看机器稿」回看第一次转写。
5. 在启动终端按 Ctrl+C 停止。再次启动可读回已保存的录音和版本。

## 数据存在哪里

- 默认录音库为 `~/Library/Application Support/Local Audio Workbench/Recordings`。音频、文件名、机器稿和校对稿都保存在录音库。系统备份或其他工具对该目录的处理取决于你的设置。
- 要单独试用，可运行 `/bin/zsh ./Start.command --port 8880 --data-dir ~/workbench-demo`。录音库必须在源码目录外。对于已有目录，当前用户须拥有该目录，其他用户须无访问权限。新目录会按此权限创建。
- 工作台只监听 `127.0.0.1`，网页与转写程序均使用本机文件。它面向受信任的单人电脑。在服务开启期间，同一台电脑上的其他本地程序可能访问本机工作台。共享电脑请只试用合成样本。
- 仓库只提供虚构演示文本和生成脚本。Apple 系统语音生成的 WAV 供个人本机试用。反馈问题时可附复现步骤和虚构文本。请把音频、真实文件名、转写、包含这些信息的截图和录音库留在本机。

## 常见问题

- **检查提示语音资产不可用。** 确认 macOS 支持 Apple Speech，且系统已安装简体中文语音资产。本工具只使用已安装的资产。工具链与资产的初次安装可能需要联网。
- **端口已占用。** 加上 `--port 8880`，再访问终端指示的地址。
- **音频无法转写或播放。** 先生成并使用演示 WAV，再试短的 WAV 或 M4A。单文件上限 64 MiB。解码受系统和浏览器支持的格式影响。
- **重复导入只看到一条。** 工作台按音频内容校验值去重。同一音频会打开已有记录。
- **校对提示版本变化。** 先复制本页草稿，再重新打开录音，合并另一窗口的改动后保存。

当前界面和转写使用简体中文。工作台提供手动导入、回听与校对，不包含采集、同步、自动摘要或协作功能。

欢迎用虚构样本报告问题，也欢迎提交安装说明、测试和交互改进。
